Bubble sort

Swap neighbours that are out of order. Each sweep carries the biggest value to the end.

USE IT WHEN
You can only swap neighbours, or you want to check if a row is already sorted in one pass.
WHY IT MATTERS
It's the last of three basic sorts. Merge sort, the first fast one, comes next.
