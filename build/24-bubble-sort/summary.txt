POST 24 · Bubble Sort (concept, 8 slides, video 37s, about 2 min)

01 COVER: Bubble sort — Swap neighbours that are out of order. Each sweep carries the biggest value to the end.
    promise: You'll write bubble sort in {lines} lines.
    use it when: You can only swap neighbours, or you want to check if a row is already sorted in one pass.
    why it matters: It's the last of three basic sorts. Merge sort, the first fast one, comes next.
02 VIDEO: Watch it sort
    lead: Bubble sort on 5 2 4 1 3, one swap at a time.
    video: 8 steps on [5, 2, 4, 1, 3]; ends: 7 swaps. Sweep 4 swaps nothing, so it stops.

03 STORY: Swap neighbours
    scene: Kids stand in a line. Walk along it: whenever a taller kid stands just before a shorter one, they swap places.
    card: After one walk the tallest kid is at the back for good. Each walk is a [[sweep]], and each sweep fixes one more spot.
    (previous footer says: The tallest walks to the back →)
04 PICTURE: The 5 bubbles up
    lead: Sweep 1 of the video, up close. The 5 keeps winning, so it keeps moving right.
    text: A sweep with no swap means every pair is in order. Then you can stop early.
    quick check: Bubble sort with the early stop on 1 2 3 5 4. How many sweeps run?  ->  Answer: 2 sweeps. Sweep 1 swaps 5 and 4; sweep 2 swaps nothing and stops.
    (previous footer says: Sweep 1, up close →)
05 EXTRA: Big ones race ahead
    text: A big value can travel to the end in one sweep. A small value moves only one step left per sweep, so it decides how long the sort runs.
    (previous footer says: The answer, then the sweeps →)

07 TRAP: Stop after a sweep
    lead: Indent the early stop one level too far and it runs after every pair.
    wrong: for j ...: |     if not swapped: return -> 2 4 1 3 5  (Sweep 2 sees 2 < 4 and quits.)
    right: for j ...: ... | if not swapped: return -> 1 2 3 4 5
    cost: Worst case O(n²), Sorted input O(n), Extra space O(1)
    (previous footer says: The bug that gives 2 4 1 3 5 →)
