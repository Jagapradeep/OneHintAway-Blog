Asked for every group you could choose from a small set? For each value, pick it, then skip it. Worked example: every subset of **1 2 3** (LeetCode 78).

## The idea

Three snacks are on the table. For each one you decide: into the lunchbox, or leave it out. One snack gives 2 lunchboxes, two give 2 × 2 = 4, and three give 2 × 2 × 2 = 8, the empty box included.

The code makes the same choices in order. At value `i`, it first **picks** it: add `nums[i]` to the `picked` list and decide the rest. Then it **skips** it: remove that last pick and decide the rest again. When every value has been decided, `picked` is one subset, and a copy of it is saved.

One list serves every subset because of the undo. Removing the last pick takes the list back to what it was, so the skip branch starts clean. This pick, explore, undo rhythm is backtracking, and the next posts build on it.

## The walk

Every subset of 1 2 3, in the order the code saves them:

| Choices | Saved |
| --- | --- |
| pick 1, pick 2, pick 3 | [1 2 3] |
| pick 1, pick 2, skip 3 | [1 2] |
| pick 1, skip 2, pick 3 | [1 3] |
| pick 1, skip 2, skip 3 | [1] |
| skip 1, pick 2, pick 3 | [2 3] |
| skip 1, pick 2, skip 3 | [2] |
| skip 1, skip 2, pick 3 | [3] |
| skip 1, skip 2, skip 3 | [] |

The first four pick 1; the last four are the same four without it.

Quick check: 1 2 3 4 has **16** subsets. The 4 doubles the 8: each one with it, and without it.

## Pseudocode

`build` decides value `i` and recurses; `subsets` starts it with nothing picked.

```
function build(nums, i, picked, out):
    if i == length(nums):
        add a copy of picked to out
    else:
        add nums[i] to picked   // pick
        build(nums, i + 1, picked, out)
        remove last from picked   // skip
        build(nums, i + 1, picked, out)
function subsets(nums):
    out = empty list
    build(nums, 0, empty list, out)
    return out
```

**The trap:** write `add picked to out` on line 3, without the copy. Every saved entry is then the same list, and the undos empty it, so `subsets([1, 2, 3])` returns 8 empty lists instead of [1 2 3] [1 2] [1 3] [1] [2 3] [2] [3] [].

## Java

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private void build(int[] nums, int i, List<Integer> picked, List<List<Integer>> out) {
        if (i == nums.length) {
            out.add(new ArrayList<>(picked)); // a copy
        } else {
            picked.add(nums[i]); // pick
            build(nums, i + 1, picked, out);
            picked.remove(picked.size() - 1); // skip
            build(nums, i + 1, picked, out);
        }
    }

    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> out = new ArrayList<>();
        build(nums, 0, new ArrayList<>(), out);
        return out;
    }
}
```

## Python

```python
def build(nums, i, picked, out):
    if i == len(nums):
        out.append(list(picked))  # a copy
    else:
        picked.append(nums[i])  # pick
        build(nums, i + 1, picked, out)
        picked.pop()  # skip
        build(nums, i + 1, picked, out)


def subsets(nums):
    out = []
    build(nums, 0, [], out)
    return out
```

## C++

```cpp
#include <vector>
using namespace std;

void build(const vector<int>& nums, int i, vector<int>& picked, vector<vector<int>>& out) {
    if (i == (int)nums.size()) {
        out.push_back(picked); // a copy
    } else {
        picked.push_back(nums[i]); // pick
        build(nums, i + 1, picked, out);
        picked.pop_back(); // skip
        build(nums, i + 1, picked, out);
    }
}

vector<vector<int>> subsets(const vector<int>& nums) {
    vector<vector<int>> out;
    vector<int> picked;
    build(nums, 0, picked, out);
    return out;
}
```

## JavaScript

```javascript
function build(nums, i, picked, out) {
    if (i === nums.length) {
        out.push([...picked]); // a copy
    } else {
        picked.push(nums[i]); // pick
        build(nums, i + 1, picked, out);
        picked.pop(); // skip
        build(nums, i + 1, picked, out);
    }
}

function subsets(nums) {
    const out = [];
    build(nums, 0, [], out);
    return out;
}
```

## Complexity

| | Cost | Why |
| --- | --- | --- |
| Time | O(n · 2ⁿ) | 2ⁿ subsets, each copied in up to n steps |
| Call depth | O(n) | One call per value decided |
| Output | O(n · 2ⁿ) | The subsets themselves |

## How it was tested

Pick or skip was run in Java, Python, C++ and JavaScript on 1,308 inputs: hand-picked inputs (1 2 3, one value, two values, negatives, ten values) and random sets of up to 8 distinct values from −10 to 10. Every output matched a brute force that reads each subset off the bits of a counter, highest bit first, so the order matches pick-before-skip. The pick and skip steps in the walk-through, the quick-check answer and the trap result come from running the code.
