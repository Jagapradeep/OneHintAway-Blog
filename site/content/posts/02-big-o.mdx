Companion code for the One Hint Away post on Big-O. Every function below was run in Java, Python, C++ and JavaScript, and all four produced the same step counts. The two Contains Duplicate solutions were checked against each other in every language on more than 3,000 random and edge-case inputs with zero mismatches.

## Step counts measured by running the code

| Shape | Function | 10 items | 100 items | 1,000 items |
|---|---|---|---|---|
| O(1) | `firstItem` | 1 | 1 | 1 |
| O(log n) | `halvings` | 3 | 6 | 9 |
| O(n) | `onePass` | 10 | 100 | 1,000 |
| O(n) | `twoPasses` | 20 | 200 | 2,000 |
| O(n²) | `everyPair` | 100 | 10,000 | 1,000,000 |

`halvings(1,000,000)` returns 19.

## Pseudocode

```
function onePass(nums):
    steps = 0
    for each x in nums:
        steps = steps + 1
    return steps          // n

function everyPair(nums):
    steps = 0
    for each x in nums:
        for each y in nums:
            steps = steps + 1
    return steps          // n * n

function halvings(n):
    steps = 0
    while n > 1:
        n = floor(n / 2)
        steps = steps + 1
    return steps

function twoPasses(nums):
    steps = 0
    for each x in nums:
        steps = steps + 1
    for each x in nums:
        steps = steps + 1
    return steps          // 2 * n, still O(n)
```

Contains Duplicate, both ways:

```
// O(n * n) time, O(1) space
function containsDuplicateBrute(nums):
    for i from 0 to length(nums) - 1:
        for j from i + 1 to length(nums) - 1:
            if nums[i] == nums[j]:
                return true
    return false

// O(n) time, O(n) space
function containsDuplicate(nums):
    seen = empty set
    for each x in nums:
        if x in seen:
            return true
        add x to seen
    return false
```

## Java

```java
import java.util.HashSet;
import java.util.Set;

public class BigO {
    static long halvings(long n) {
        long steps = 0;
        while (n > 1) {
            n = n / 2;
            steps = steps + 1;
        }
        return steps;
    }

    static long onePass(int[] nums) {
        long steps = 0;
        for (int x : nums) {
            steps = steps + 1;
        }
        return steps;
    }

    static long everyPair(int[] nums) {
        long steps = 0;
        for (int x : nums) {
            for (int y : nums) {
                steps = steps + 1;
            }
        }
        return steps;
    }

    static long twoPasses(int[] nums) {
        long steps = 0;
        for (int x : nums) {
            steps = steps + 1;
        }
        for (int x : nums) {
            steps = steps + 1;
        }
        return steps;
    }

    // O(n * n) time, O(1) space
    static boolean containsDuplicateBrute(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[i] == nums[j]) {
                    return true;
                }
            }
        }
        return false;
    }

    // O(n) time, O(n) space
    static boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            if (seen.contains(x)) {
                return true;
            }
            seen.add(x);
        }
        return false;
    }
}
```


`Math.floor` matters in `halvings`: in JavaScript, `/` always gives a decimal, so `7 / 2` is `3.5`, not `3`.

## Complexity summary

| Function | Time | Extra space |
|---|---|---|
| `halvings` | O(log n) | O(1) |
| `onePass`, `twoPasses` | O(n) | O(1) |
| `everyPair` | O(n²) | O(1) |
| `containsDuplicateBrute` | O(n²) | O(1) |
| `containsDuplicate` | O(n) on average | O(n) |
