**Problem:** [LeetCode 268. Missing Number](https://leetcode.com/problems/missing-number/) (Easy). `nums` holds n distinct numbers from the range 0 to n; return the one number from that range that is missing.

**Idea:** value `v` belongs in seat (index) `v`. Swap each number into its own seat; a number with no seat (`v == n`) is skipped. Then scan: the first seat `i` that does not hold `i` is the missing number. If every seat matches, the missing number is `n`.

**Worked example:** `[3, 0, 4, 1, 5]` becomes `[0, 1, 5, 3, 4]` after 3 swaps; seat 2 holds 5, so the answer is **2**. Quick check: `[1, 2, 0]` becomes `[0, 1, 2]`, every seat matches, so the answer is **3**.

## Pseudocode

```
function missingNumber(nums):
    n = length(nums)
    i = 0
    while i < n:
        seat = nums[i]
        if seat < n and nums[seat] != seat:
            swap nums[i], nums[seat]
        else:
            i = i + 1          // home, or no seat
    for i from 0 to n - 1:
        if nums[i] != i:       // wrong number
            return i
    return n
```

## Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static int missingNumber(int[] nums) {
        int n = nums.length;
        int i = 0;
        while (i < n) {
            int seat = nums[i];
            if (seat < n && nums[seat] != seat) {
                int tmp = nums[i];
                nums[i] = nums[seat];
                nums[seat] = tmp;
            } else {
                i = i + 1;
            }
        }
        for (i = 0; i < n; i++) {
            if (nums[i] != i) return i;
        }
        return n;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int k = 0; k < t; k++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int n = Integer.parseInt(st.nextToken());
            int[] nums = new int[n];
            for (int j = 0; j < n; j++) nums[j] = Integer.parseInt(st.nextToken());
            out.append(missingNumber(nums)).append('\n');
        }
        System.out.print(out);
    }
}
```

## Python

```python
import sys

def missing_number(nums):
    n = len(nums)
    i = 0
    while i < n:
        seat = nums[i]
        if seat < n and nums[seat] != seat:
            nums[i], nums[seat] = nums[seat], nums[i]
        else:
            i = i + 1
    for i in range(n):
        if nums[i] != i:
            return i
    return n

def main():
    data = sys.stdin.read().split("\n")
    t = int(data[0])
    out = []
    for k in range(1, t + 1):
        parts = list(map(int, data[k].split()))
        out.append(str(missing_number(parts[1:])))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```

```javascript
function missingNumber(nums) {
    const n = nums.length;
    let i = 0;
    while (i < n) {
        const seat = nums[i];
        if (seat < n && nums[seat] !== seat) {
            [nums[i], nums[seat]] = [nums[seat], nums[i]];
        } else {
            i = i + 1;
        }
    }
    for (i = 0; i < n; i++) {
        if (nums[i] !== i) return i;
    }
    return n;
}
```

## Complexity

- **Time:** O(n). Every swap puts one number in its own seat for good, so there are at most n swaps, plus one scan.
- **Extra space:** O(1). The swaps happen inside `nums` (note: this reorders the input array).

Each program reads test cases from standard input: the first line is the number of cases, then one line per case with `n` followed by the `n` numbers.

**Tested:** all four agree with a brute-force check on 2,014 cases (2,000 random arrays with n from 1 to 12, plus edge cases: single element, missing 0, missing n, reversed, and three arrays at the maximum size n = 10,000).
