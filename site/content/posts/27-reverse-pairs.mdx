Counting pairs `i < j` where the left value is more than double the right? Merge sort can count them while it sorts. Worked example: **LeetCode 493, Reverse Pairs** (Hard).

## The idea

Kids stand in a line. A kid is a giant to anyone behind them who is less than half their height, and we count every giant pair. In array terms: count the pairs `i < j` with `nums[i] > 2 * nums[j]`. For [6, 4, 1, 5, 2] there are 4: (6, 1), (6, 2), (4, 1), (5, 2).

1. **Check every pair.** It works, but it is n(n − 1)/2 checks: over a billion for 50,000 values.
2. **Sorted halves count fast.** Split the line in two. Every pair is either inside the left half, inside the right half, or across. If both halves are sorted, the pairs across line up: once a left value pairs with a right value r, every bigger left value pairs with r too.
3. **Merge sort does the sorting.** Merge sort ([post 25](/posts/merge-sort/)) already splits the line and hands back sorted halves just before each merge. Pairs inside a half are the same problem, smaller, so the function calls itself. Pairs across are counted, then the halves are merged.
4. **One walk across.** For each right value r, move a pointer `i` past the left values that are at most `2 * r`. Every left value from `i` to the end of the left half pairs with r. The right half is sorted, so r only grows and `i` never walks back: one walk per merge. `2 * r` can pass the 32-bit limit, so it is kept in 64 bits.

## The walk

On [6, 4, 1, 5, 2], counting across just before each merge:

| Left half | Right half | Pairs across | Running total |
| --- | --- | --- | --- |
| 6 | 4 | 0 | 0 |
| 4 6 | 1 | 2 (6 and 4 with 1) | 2 |
| 5 | 2 | 1 (5 with 2) | 3 |
| 1 4 6 | 2 5 | 1 (6 with 2) | 4 |

Quick check: with sorted halves 3 7 9 and 1 4, there are **4 pairs across**: 1 pairs with 3, 7 and 9, and 4 pairs only with 9.

## Pseudocode

`reversePairs` starts the count; `countPairs` splits, counts inside each half, counts across, then merges.

```
function reversePairs(nums):
    n = length(nums)
    return countPairs(nums, 0, n - 1)

function countPairs(nums, low, high):
    if low >= high:
        return 0
    mid = floor((low + high) / 2)
    left = countPairs(nums, low, mid)
    right = countPairs(nums, mid + 1, high)
    count = left + right
    i = low
    for j from mid + 1 to high:
        twice = 2 * nums[j]   // 64-bit
        while i <= mid and nums[i] <= twice:
            i = i + 1
        count = count + mid - i + 1
    merge the two sorted halves   // post 25
    return count
```

**The trap:** `2 * nums[j]` overflows a 32-bit integer when `nums[j]` is near 2³¹ − 1 or −2³¹. Keep it in a 64-bit integer (`long` in Java, `long long` in C++). Python and JavaScript numbers are big enough here.

## Java

```java
class Solution {
    public int reversePairs(int[] nums) {
        int n = nums.length;
        return countPairs(nums, 0, n - 1);
    }

    private int countPairs(int[] nums, int low, int high) {
        if (low >= high) {
            return 0;
        }
        int mid = (low + high) / 2;
        int left = countPairs(nums, low, mid);
        int right = countPairs(nums, mid + 1, high);
        int count = left + right;
        int i = low;
        for (int j = mid + 1; j <= high; j++) {
            long twice = 2L * nums[j]; // 64-bit: no overflow
            while (i <= mid && nums[i] <= twice) {
                i++;
            }
            count += mid - i + 1;
        }
        merge(nums, low, mid, high); // the merge from post 25
        return count;
    }

    private void merge(int[] nums, int low, int mid, int high) {
        int[] merged = new int[high - low + 1];
        int a = low, b = mid + 1, k = 0;
        while (a <= mid && b <= high) {
            merged[k++] = nums[a] <= nums[b] ? nums[a++] : nums[b++];
        }
        while (a <= mid) merged[k++] = nums[a++];
        while (b <= high) merged[k++] = nums[b++];
        System.arraycopy(merged, 0, nums, low, merged.length);
    }
}
```

## Python

```python
def reverse_pairs(nums):
    n = len(nums)
    return count_pairs(nums, 0, n - 1)


def count_pairs(nums, low, high):
    if low >= high:
        return 0
    mid = (low + high) // 2
    left = count_pairs(nums, low, mid)
    right = count_pairs(nums, mid + 1, high)
    count = left + right
    i = low
    for j in range(mid + 1, high + 1):
        twice = 2 * nums[j]
        while i <= mid and nums[i] <= twice:
            i += 1
        count += mid - i + 1
    merge(nums, low, mid, high)  # the merge from post 25
    return count


def merge(nums, low, mid, high):
    merged = []
    a, b = low, mid + 1
    while a <= mid and b <= high:
        if nums[a] <= nums[b]:
            merged.append(nums[a])
            a += 1
        else:
            merged.append(nums[b])
            b += 1
    merged += nums[a:mid + 1] + nums[b:high + 1]
    nums[low:high + 1] = merged
```

## C++

```cpp
#include <vector>
using namespace std;

void merge(vector<int>& nums, int low, int mid, int high) {
    vector<int> merged;
    int a = low, b = mid + 1;
    while (a <= mid && b <= high) {
        merged.push_back(nums[a] <= nums[b] ? nums[a++] : nums[b++]);
    }
    while (a <= mid) merged.push_back(nums[a++]);
    while (b <= high) merged.push_back(nums[b++]);
    for (int k = 0; k < (int)merged.size(); k++) nums[low + k] = merged[k];
}

int countPairs(vector<int>& nums, int low, int high) {
    if (low >= high) {
        return 0;
    }
    int mid = (low + high) / 2;
    int left = countPairs(nums, low, mid);
    int right = countPairs(nums, mid + 1, high);
    int count = left + right;
    int i = low;
    for (int j = mid + 1; j <= high; j++) {
        long long twice = 2LL * nums[j]; // 64-bit: no overflow
        while (i <= mid && nums[i] <= twice) {
            i++;
        }
        count += mid - i + 1;
    }
    merge(nums, low, mid, high); // the merge from post 25
    return count;
}

int reversePairs(vector<int>& nums) {
    int n = nums.size();
    return countPairs(nums, 0, n - 1);
}
```

## Complexity

| | Cost | Why |
| --- | --- | --- |
| Time | O(n log n) | About log n levels, and each level does one O(n) walk and one O(n) merge |
| Extra space | O(n) | The merge's buffer |
| Check every pair | O(n²) | The slow way it replaces |

## How it was tested

The merge-sort count was run in Java, Python, C++ and JavaScript on 1,017 inputs: hand-picked cases (one value, two values, the LeetCode examples, sorted, reversed, all equal, negatives, zeros, and values at both 32-bit limits where 2 × value overflows 32 bits), one array of 2,000 random 32-bit values, random arrays of up to 14 small values and random arrays of up to 30 values from the whole 32-bit range. Every output matched a brute force that checks every pair. The pair counts at each merge and the quick-check answer come from running the code.
